1️⃣ Check logs for v2 version:
   docker exec kind-vap-patch-control-plane bash -c 'find /var/log/pods -name "0.log" -path "*kube-apiserver*" 2>/dev/null | head -1 | xargs cat 2>/dev/null | grep "v2-fix"'
   
   Should see: "v2-fix-eviction-20mb" ✅

2️⃣ Check memory usage:
   docker stats kind-vap-patch-control-plane --no-stream
   
   Should see: ~474MB (not 2.5GB+) ✅

3️⃣ Check Docker image version:
   docker inspect kind-vap-patch-control-plane 2>/dev/null | grep -i "image.*vap"
   
   Should see: "vap-lru-cache-optimized:v2-fix-eviction-20mb" ✅

4️⃣ Check all patch markers:
   docker exec kind-vap-patch-control-plane bash -c 'find /var/log/pods -name "0.log" -path "*kube-apiserver*" 2>/dev/null | head -1 | xargs cat 2>/dev/null | grep -i "patch\|LRU_CACHE"'
   
   Should see multiple v2 markers ✅

Q: Cluster is not running
A: Create it with:
   kind create cluster --config /tmp/kind-config-v2.yaml

Q: Can't find log file
A: The log file may not exist yet. Wait 30 seconds after cluster creation.

Q: Seeing v1 markers instead of v2
A: Delete and recreate cluster:
   kind delete cluster --name kind-vap-patch
   kind create cluster --config /tmp/kind-config-v2.yaml

Q: Memory is still 2.5GB+
A: v1 image might still be running. Check:
   docker inspect kind-vap-patch-control-plane | grep -i image
   Should be: vap-lru-cache-optimized:v2-fix-eviction-20mb
